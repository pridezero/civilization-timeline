玩法说明

如何游玩「文明刻度」

穿越时空的年代学家——请把人类文明的成果，放回它们本来的位置。

基本流程

1. 观察手牌

每关你会获得若干张历史卡牌。卡牌正面显示文物图像、名称和线索，但不显示年代。仔细阅读线索，从中推断可能的时期。

2. 推断位置

中央时间轴上已有一张基准卡，公开其年代。根据线索判断手牌应该插入时间轴的哪个位置——最左、最右，或两张卡之间。

3. 选择信心

选中手牌并选择位置后，你需要选择自己的信心等级——稳妥（倍率 x1）、笃定（x2）、直觉（x3）。信心越高，得分越多，但放错时失误代价也越大。

4. 确认放置

点击「确认放置」揭晓真实年代。正确则卡牌留在时间轴，放错则卡牌弹回手牌。每放对一张，牌库会自动补入新卡。

Roguelike 关卡

每次探索由 3 个关卡 组成，难度递增：

  • 第 1 关 — 12 张卡，难度 1-2 星（入门）
  • 第 2 关 — 16 张卡，难度 1-3 星（进阶）
  • 第 3 关 — 20 张卡，难度 2-3 星（挑战）

每关的失误次数独立计算（默认 8 次），通关后时间轴清空、手牌与血量重置，但累计分数保留。

遗物系统

通过第 1 关和第 2 关后，会从 3 件随机遗物中选择 1 件。遗物效果持续到本次探索结束：

  • 🔍 考古学家 — 每关首次使用「补充线索」不计惩罚
  • ⏳ 年代学家 — 连击倍率上限从 3.0 提升至 4.0
  • 🎲 赌徒 — 直觉信心倍率从 x3 提升至 x4，但每关最大容错减少 2 次

不同遗物组合会产生截然不同的策略体验，谨慎选择！

计分规则

  • 基础得分 = 卡牌难度 x 100（1 星 100 分，2 星 200 分，3 星 300 分）
  • 连击加成 = 基础得分 x 连击倍率（每连续正确 1 次 +0.2，上限 3.0）
  • 信心倍率 = 稳妥 x1 / 笃定 x2 / 直觉 x3
  • 错误代价 = 放错按信心等级增加失误（稳妥 +1 / 笃定 +2 / 直觉 +3）
  • 套组加成（通关结算时额外计算）：
    • 同类别连放 3+ 张：+100 x (L-2)
    • 覆盖 4+ 个不同区域：+150 x (D-3)
    • 相邻不同文明且年代差 < 200 年：+150 / 对

其他机制

  • 补充线索 — 每张牌可用一次，揭示更多信息，但扣减最终得分
  • 近失提示 — 放错时如果只差 300 年以内，会显示"只差 N 年！"的提示
  • 文明图鉴 — 正确放置的卡牌会解锁到图鉴中，可在首页「📜 图鉴」查看
  • 区间判定 — 部分卡牌有年代区间（如"公元前 500-400 年"），只要插入位置不与其他卡区间矛盾即为正确
